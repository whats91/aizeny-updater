# Security reporting

Do not open a public issue for a suspected malicious or tampered AI Zeny
release, an exposed credential or a signing-key incident.

Use GitHub's private vulnerability reporting for this repository when it is
enabled, or contact the AI Zeny owner privately through the support channel
already provided to your organization. Never attach secrets, private keys,
device credentials, Local API tokens, customer data or full diagnostic archives
to an unencrypted message.

The detached signature of the release manifest is the authorization boundary.
Published versions are immutable: a version number is never reused, and release
assets are never replaced.
